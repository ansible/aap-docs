= Subscription lifecycle timeline

[role="_abstract"]
Review the post-subscription timeline, grace periods, and data retention windows to prevent service disruption and permanent environment deletion after your AWS subscription ends.

== Contract end (Day 0)

* AWS stops all billing for your AWS subscription.
* AWS sends Red Hat a contract-ended notice.
* Your environment remains fully operational.
* No immediate action is taken.

== 0 to 72 hours post-contract-end

* Red Hat holds the contract-ended notice for approximately 72 hours.
* Your environment remains available and fully operational during this window.
* If you establish a new AWS subscription using the same AWS account during this period, your environment continues uninterrupted with no data loss.

== After 72 hours (no new AWS subscription)

* If no new AWS subscription is detected, Red Hat initiates environment shutdown.
* Job execution ceases.
* Environment resources are spun down.
* Your environment data is retained but not actively running.

== 72 hours to 14 days post-shutdown

* Your environment data is retained for approximately 14 days after shutdown
* If you establish a new AWS subscription using the same AWS account during this window, your environment can be restored.
* Administrative support may be required to link the new subscription to your existing environment.

== After 14 days (no new AWS subscription)

* If no new AWS subscription has been established, your environment is permanently deleted.
* Recovery is not possible after this point.
