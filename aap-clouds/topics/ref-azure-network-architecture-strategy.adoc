= Network architecture strategy

[role="_abstract"]
Determine the networking requirements for the new deployment. You can choose to keep the original network settings (CIDR ranges, etc.) to minimize configuration issues.

[WARNING]
====
*Network Configuration Immutability*

Network configurations (such as CIDR ranges) cannot be changed after the deployment is complete. Verify these parameters carefully before deploying.
====
