= Deleting {AAPonAzureNameShort} deployments

[role="_abstract"]
You can gracefully cancel an {AAPonAzureNameShort} deployment. 

Deleting the managed application automatically removes its associated managed resource group and all deployed infrastructure (virtual machines, storage, and networking).

[WARNING]
====
Deleting the application is permanent. All configuration data, project syncs, execution history, and active automation workflows will be destroyed.
====

.Prerequisites

An Azure account with permissions to delete resources in the subscription or resource group, for example, Owner or Contributor role.

.Procedure

. Sign in to the link:https://portal.azure.com/[Azure portal].
. In the top search bar, type *Managed Applications* and select it from the services list.
. In the list of managed applications, locate and click the name of your {PlatformNameShort} instance.
. From the top action toolbar on the Overview page, click btn:[Delete].
. In the confirmation dialog, type `yes` (or the name of the application, if prompted) to verify.
. Click btn:[Delete] to begin removal.

.Verification

. In the global navigation bar, click the Notifications image:bell.png[15,15] icon to monitor deletion progress.
. When the notification confirms deletion is complete, navigate back to *Managed Applications* and verify the instance no longer appears.
. Navigate to *Resource groups* and verify that the managed resource group associated with the deployment (typically prefixed with `mrg-`) has been removed.
