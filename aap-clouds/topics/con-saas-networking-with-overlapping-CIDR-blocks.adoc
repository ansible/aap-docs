= Networking with overlapping CIDR blocks

[role="_abstract"]
Automation mesh connects the control plane to networks sharing the same CIDR block across clouds or data centers. Because execution nodes treat their deployment network as local, pair at least one execution node instance with an instance group to target automation in each network.
