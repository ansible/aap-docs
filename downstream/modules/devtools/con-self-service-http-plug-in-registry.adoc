= HTTP plug-in registry

[role="_abstract"]
The HTTP plug-in registry method hosts plug-in tarball files in a local OpenShift registry that the dynamic plug-in installer pulls during startup.

[NOTE]
====
The HTTP plug-in registry method is deprecated and will be removed in a future release of {PlatformNameShort}. Starting with portal release v2.3.0, the Helm chart defaults to OCI container delivery (`pluginMode: oci`). Follow the HTTP plug-in registry procedure only if you require a manual values override (`pluginMode: tarball`).
====
