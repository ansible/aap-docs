== Overview

This Ansible Automation Platform 2.5 async release contains a security update for Receptor. It fixes a vulnerability in the Go crypto/x509 library that could allow man-in-the-middle attacks through untrusted intermediate certificates. We recommend that all Ansible Automation Platform 2.5 users apply this update.
