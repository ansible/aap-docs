= Ansible automation portal patch release October 21, 2026 (portal-2.2.10)


[role="_abstract"]
The following security remediations and bug fixes have been implemented in this release of Ansible automation portal.

This release includes the following components and versions:

== Overview

Red Hat Ansible automation portal 2.2.10 is a security and bug fix update. This release delivers third-party dependency security patches across automation portal plugins and the RHEL bootc appliance, and fixes custom TLS certificate configuration when `network.base_url` is set on the appliance.

== Features

This release includes no new features.

== Highlights

* *Security*: Third-party dependency updates address vulnerabilities in portal plugins (adm-zip, multer, vm2, scaffolder, proxy-addr, source-map-js) and the RHEL appliance (nodemailer, node-forge, compression, isomorphic-git, graphql-tools, redis-parser, basic-ftp, vm2).
* *Bug fix*: Custom TLS certificates with a DNS hostname in `network.base_url` on the RHEL appliance no longer cause OAuth and catalog TLS hostname mismatch failures without manual discovery and hosts configuration. (AAP-82546)

== Enhancements

No enhancements are included in this release.

== Bug fixes

=== Ansible automation portal RHEL appliance

* Previously, configuring a custom TLS certificate with a hostname `network.base_url` on the Automation Portal RHEL appliance could cause OAuth and catalog requests to fail with a TLS certificate hostname mismatch (`ERR_TLS_CERT_ALTNAME_INVALID`). The appliance now automatically configures discovery endpoints and local hostname resolution when `network.base_url` is a DNS hostname, so custom SSL certificates work without additional manual configuration. (AAP-82546)

== Changed features

* Ansible automation portal Helm chart sets `redhat-developer-hub.global.pluginMode` to `oci` by default. Each plug-in is referenced with a package value such as `oci://registry.redhat.io/ansible-automation-platform/automation-portal:2.3!<plugin-name>`. Before you upgrade, migrate Helm values that use an HTTP plug-in registry or tarball package URLs. For more information, see the Ansible automation portal upgrade guide.
