== Overview

Red Hat Ansible Automation Platform portal 2.1.7 is a security and bug fix update. This release fixes a catalog redirect issue in dynamic plugin deployments.

== Highlights

* *Bug fix:* Navigating to `/catalog` now redirects to the permission-filtered self-service catalog instead of the unfiltered Backstage catalog. (AAP-88645)
* *Security:* Third-party dependency updates address vulnerabilities in the automation portal plugins.

== Bug fixes

=== Ansible automation portal

* Fixed an issue where navigating to `/catalog` showed the unfiltered Backstage catalog instead of the permission-filtered self-service catalog. (AAP-88645)
