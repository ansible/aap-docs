== Overview

This release of Red Hat {PlatformNameShort} 2.5.20260824 includes 24 security updates, 1 enhancements, and 3 bug fixes across 8 components. The release addresses critical vulnerabilities in Controller, Hub, and Lightspeed, including fixes for path traversal, remote code execution, and denial-of-service vulnerabilities.
