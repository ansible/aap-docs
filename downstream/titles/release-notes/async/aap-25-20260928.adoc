== Overview

Red Hat Ansible Automation Platform portal 2.1.8 is a security patch update for the AAP 2.5 plugin stream. This release delivers third-party dependency security patches in automation portal plugins. No RHEL bootc appliance or OpenShift operator changes are included in the 2.1.8 scope.

== Features

No new features are included in this release.

== Highlights

* *Security:* Third-party dependency updates address vulnerabilities in automation portal plugins, mirroring the portal-2.2.8 CVE set plus an additional Immutable.js denial-of-service fix and multer upload handling on the 2.1 release branch.

== Bug fixes

No customer-facing bug fixes beyond security remediations are included in this release.
