== Overview
The updates cover automation controller and supported execution environments, including security fixes, reliability improvements, and expanded configuration options for notification destinations.

== Highlights

* Key changes include protection against token forgery, authentication bypass, and unauthenticated disruption of job dispatch. Controller improvements address fact caching for sliced jobs, database locking during concurrent job completion, and administrator control over notification destinations.

== Bug fixes

=== Controller

* Fixed an issue where host facts were not updated for sliced jobs. (AAP-99482)
* Fixed an issue where concurrent job completions on a job template with `allow_simultaneous` enabled could cause row-level lock convoys on the `main_unifiedjobtemplate` table, leading to API unresponsiveness. The parent job template update now uses PostgreSQL `SKIP LOCKED` to avoid queuing behind locked rows, allowing concurrent updaters to return immediately instead of waiting. (AAP-96775)
* Fixed an issue where notification SSRF protection blocked all private, loopback, and link-local addresses without an override option. Notification SSRF protection now supports an administrator-configurable allowlist for permitting specific internal IP ranges or hostnames as notification destinations. (AAP-95787)
