== Overview
This async release of Red Hat Ansible Automation Platform 2.5, scheduled for 2 November 2026, updates the collections in the supported execution environment and fixes a security vulnerability in the python3.12-brotli package. For more information, see link:https://access.redhat.com/errata/RHSA-2026:94100?__atl_rovo=disable_public_resolution[RHSA-2026:94100].
