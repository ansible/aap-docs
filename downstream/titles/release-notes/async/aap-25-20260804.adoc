== Overview

Red Hat {PlatformNameShort} 2.5 (2.5.20260804) delivers a new feature for the metrics service, an execution environment collection update, and addresses multiple security vulnerabilities across {ControllerNameStart}, {ExecEnvShort}, {HubNameStart}, Ansible Lightspeed, and Receptor. This release also resolves bug fixes in the AAP Gateway, Controller scheduling and role management, Event-Driven Ansible, and the Platform Operator backup process.

== Bug fixes

=== Aap-gateway

* Fixed an issue where the Gateway API returned 403 "Action not allowed from proxy" on PATCH/PUT to service_clusters when the gateway route had `enable_gateway_auth=False`. (AAP-83438)

=== Controller

* Fixed an issue where AAP Controller failed to load subscriptions when using Satellite (`REDHAT_CANDLEPIN_HOST`) because `validate_rh()` only used the configured host as a fallback when `rhsm.conf` was missing, and `get_satellite_subs()` ignored `REDHAT_CANDLEPIN_VERIFY`, making it impossible to configure TLS verification for Satellite connections via settings. (AAP-84437)
* Fixed an issue where Organization child admin roles did not contain the `view_team` permission, causing team role assignment to return "Invalid pk" after upgrade. (AAP-84213)
* Fixed an issue where specialized Organization Admin roles were missing the `shared.member_organization` permission, causing create operations to fail with 403. Adds the permission to all six specialized Admin role definitions and connects `setup_managed_role_definitions` to the `dab_post_migrate` signal for automatic fix on upgrade. (AAP-83960)
* Fixed an issue where the task manager assigned all burst jobs to a single controller node when capacity was tied, by adding least-connections tie-breaking to prefer the instance with fewer `jobs_running`. (AAP-83715)
* Fixed an issue where the jobs page failed to load due to DB slowness. The Job list API can now optionally exclude large fields like `extra_vars` and `artifacts` through a new query parameter. (AAP-82683)


=== {EDAName}

* Fixed an issue where `test_delete_credential_tied_to_decision_env_sync` was failing. (AAP-83310)


=== Platform operator

* Fixed an issue where unnecessary file permission changes in the database backup task caused failures on storage backends enforcing POSIX identity, such as AWS EFS with access points. (AAP-84421)
* Fixed an issue where unnecessary file permission changes in the database backup task caused failures on storage backends enforcing POSIX identity, such as AWS EFS with access points. (AAP-84418)
