== Overview

This release of Ansible Automation Platform 2.4 includes performance enhancements and bug fixes for the automation controller and execution environments. Three critical bug fixes address row-level lock contention issues that could impact API responsiveness during high concurrency scenarios. Additionally, the controller collection has been updated to version 4.5.37.

== Enhancements

== Execution environments

* Controller collection updated to 4.5.37 (AAP-96285)

== Bug fixes

== Controller

* Fixed an issue where row lock convoy occurred when using oauth2 tokens excessively (AAP-93866)

* Fixed a performance issue where concurrent job completions could cause row-level lock contention on the main_host table. The last_job_id and last_job_host_summary_id fields are no longer written to main_host on every job completion. Instead, the latest job host summary is derived at read time via query, eliminating the contention point. (AAP-95886)

* Job Template Lock Convoy Prevention (AAP-95887): Fixed a performance issue where concurrent job completions on a job template with allow_simultaneous enabled could cause row-level lock convoys on the main_unifiedjobtemplate table, leading to API unresponsiveness. The parent job template update now uses PostgreSQL SKIP LOCKED to avoid queuing behind locked rows, allowing concurrent updaters to return immediately instead of waiting. (AAP-96776)
