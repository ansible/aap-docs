== Overview
This Ansible Automation Platform 2.4 maintenance update is a security update. It includes updates to Brotli to address RHSB-2026-015 (CVE-2026-111497), an Out-of-Bounds Write vulnerability in the Google Brotli Decoder. This release has no new features, enhancements, deprecations, bug fixes or known issues.

== Security Updates
* brotli
** Updated to address link:https://access.redhat.com/security/vulnerabilities/RHSB-2026-015[RHSB-2026-015] (CVE-2026-111497) – an Out-of-Bounds Write in Google Brotli Decoder.
