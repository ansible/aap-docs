== Overview

This release of Ansible Automation Platform 2.4 includes 1 security update, 1 enhancement, and 1 bug fix. This patch release addresses a critical vulnerability in the HashiCorp Vault credential plugin and includes stability improvements for Controller and Execution Environments.
