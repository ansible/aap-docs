== Overview
This Ansible Automation Platform 2.4 maintenance update (2.4.20261027) is a security update. It includes updates to ca-certificates (RHSB-2026-012) and brotli in Execution Environment (RHSB-2026-015). This release has no new features, enhancements, deprecations, bug fixes or known issues.

== Security Updates
* ca-certificates
** Updated to address link:https://access.redhat.com/security/vulnerabilities/RHSB-2026-012[RHSB-2026-012] – removes trust in compromised eMudhra intermediate certificates from the system trust store.
* Execution Environment – brotli
** Updated to address link:https://access.redhat.com/security/vulnerabilities/RHSB-2026-015[RHSB-2026-015] (CVE-2026-111497) – an out-of-bounds write flaw in the Brotli decoder.
