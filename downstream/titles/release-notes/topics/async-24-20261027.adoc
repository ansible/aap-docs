== Overview

This Ansible Automation Platform 2.4 maintenance update (2.4.20261027) is a security update. It fixes a crypto/x509 vulnerability in the receptor that could allow man-in-the-middle attacks through untrusted intermediate certificates. This release has no new features, enhancements, deprecations, bug fixes or known issues.
