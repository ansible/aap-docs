== Overview

This release of Ansible Automation Platform 2.4 includes 3 security updates addressing Common Vulnerabilities and Exposures (CVEs), 3 enhancements, and 2 bug fixes.

== Enhancements

=== {ControllerNameStart}

* Added awx-manage `create_host_summary_index` management command that creates a composite database index to improve host list page load performance. The command is safe to run on a live system (non-blocking) and can be re-run without side effects. (AAP-101617)
* Added awx-manage `create_host_summary_index` management command that creates a composite database index to improve host list page load performance. The command is safe to run on a live system (non-blocking) and can be re-run without side effects. (AAP-94167)

== Bug fixes

=== {ControllerNameStart}

* Fixed an issue where After upgrading automation controller to 4.5.37 or later, `GET /api/v2/dashboard/` could exceed the request timeout and the dashboard could show 0 hosts, on deployments with a large `main_jobhostsummary` table. This release adds the awx-manage `create_host_summary_index` command, which creates the composite index required by the dashboard's failed-hosts query.

After upgrading, run `awx-manage` `create_host_summary_index`. The index is not created automatically. The command is `idempotent` and reports "already exists" if the index was created manually beforehand. (AAP-101643)

* Fixed an issue where fixes a bug where hosts facts were not updated for sliced jobs (AAP-99481)
